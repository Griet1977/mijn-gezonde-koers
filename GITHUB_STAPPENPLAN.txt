MIJN GEZONDE KOERS V4 OP GITHUB ZETTEN

1. Download het ZIP-bestand en kies Alles uitpakken.
2. Open GitHub en open dezelfde repository als je huidige app.
3. Klik Code > Add file > Upload files.
4. Open de uitgepakte map en sleep index.html, manifest.webmanifest, sw.js, icon-192.png en icon-512.png naar GitHub.
5. GitHub mag melden dat bestanden worden vervangen. Dat is correct.
6. Vul als committekst in: Update naar Mijn Gezonde Koers v4.
7. Klik Commit changes.
8. Klik Actions en controleer of Pages build and deployment een groen vinkje krijgt.
9. Open je bestaande HTTPS-adres eerst rechtstreeks in Safari. Trek omlaag om te vernieuwen.
10. Zie je nog de oude versie, sluit Safari volledig. Open het adres opnieuw. Verwijder zo nodig alleen het oude beginschermicoon en voeg de website opnieuw toe via Delen > Zet op beginscherm.

BELANGRIJK
- Upload de uitgepakte bestanden, niet het ZIP-bestand.
- index.html moet in de hoofdmap van je repository staan.
- De app probeert lokale gegevens uit oudere versies over te nemen.
- Foto's blijven lokaal in Safari. Wis Safari-websitegegevens niet zonder back-up.
